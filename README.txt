Tasks.m runs all the algorithms required, and produces all plots required.

When Tasks.m is run, the Nelder-Mead Simplex algorithm animations will appear. Each of these animations runs for 10 seconds until convergence, then asks whether you want to see the animation again or watch the next one.

Once you have progressed through all 3 animations, you may view the figures for the first three optimisations. Optimisation paths are plotted for all three algorithms on the same plot from the same initialisation, for direct comparison.
